## Overview

Better Notes extends Zotero's note system with template creation, note trees, bulk note export to markdown, and sync with Obsidian vaults for an integrated academic writing workflow.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Zotero Better Notes** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Note Templates** | Create reusable templates applied when opening a new item note |
| **Note Tree** | Hierarchical note tree linked to collection and item structure |
| **Markdown Export** | Export all notes as Markdown files preserving formatting and links |
| **Obsidian Sync** | Two-way sync between Zotero notes and Obsidian vault files |
